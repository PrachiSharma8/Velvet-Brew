# ☕ Velvet Brew

> Good Coffee. Good Moments.

Velvet Brew is a modern, premium café website designed to showcase handcrafted coffee, fresh pastries, a warm café atmosphere, and an elegant customer experience.

This project was built as a frontend web development portfolio project with a focus on responsive design, interactive components, modern UI, and clean visual presentation.
